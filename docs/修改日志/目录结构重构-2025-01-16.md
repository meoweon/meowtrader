# 目录结构重构 - 2025-01-16

## 变更概述

将 PyInstaller 打包相关的脚本和 hooks 从 `scripts/` 移动到 `packaging/pyinstaller/`，使项目目录结构更加清晰。

## 变更内容

### 文件移动

1. **打包脚本**
   - `scripts/build.py` → `packaging/pyinstaller/build.py`
   - 更新了 `PROJECT_ROOT` 路径计算（`parent.parent` → `parent.parent.parent`）
   - 更新了 `hooks_dir` 路径引用

2. **PyInstaller Hooks**
   - `scripts/hooks/*` → `packaging/pyinstaller/hooks/`
   - 所有 6 个 hook 文件已移动

3. **根目录批处理脚本**
   - 创建了 `build.bat`（Windows 批处理脚本）
   - 自动执行清理和默认打包

### 目录结构变更

**之前**：
```
scripts/
├── build.py              # PyInstaller 打包脚本
├── hooks/                # PyInstaller hooks
│   ├── hook-jaraco.py
│   ├── hook-pkg_resources.py
│   └── ...
└── [其他通用脚本]
```

**之后**：
```
packaging/
└── pyinstaller/
    ├── build.py          # PyInstaller 打包脚本
    ├── hooks/            # PyInstaller hooks
    │   ├── hook-jaraco.py
    │   ├── hook-pkg_resources.py
    │   └── ...
    └── README.md         # 打包工具说明

scripts/
└── [通用脚本，不包含打包脚本]

build.bat                  # 根目录打包快捷脚本（新增）
```

## 影响范围

### 需要更新的使用方式

**推荐方式**（使用批处理脚本）：
```bash

```

**直接调用 Python 脚本**：
```bash
.venv/Scripts/python.exe packaging/pyinstaller/build.py
```
