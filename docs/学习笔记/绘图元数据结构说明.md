# K线图表绘图元数据结构说明

本文档说明回测K线图表绘制所需的元数据结构。

## 数据结构概览

绘图所需的数据主要分为三部分：
1. **K线历史数据** (`history`)
2. **交易配对数据** (`trade_pairs`)
3. **索引映射关系** (`dt_ix_map`, `ix_bar_map`)

---

## 1. K线历史数据 (history)

### 数据结构
```python
history: list[BarData]  # BarData 对象列表
```

### BarData 对象字段
- `datetime: datetime` - K线时间
- `open_price: float` - 开盘价
- `high_price: float` - 最高价
- `low_price: float` - 最低价
- `close_price: float` - 收盘价
- `volume: float` - 成交量
- `symbol: str` - 交易对代码
- `exchange: Exchange` - 交易所

### 用途
- 绘制K线图
- 建立时间到索引的映射关系
- 计算价格范围用于箭头位置调整

---

## 2. 交易配对数据 (trade_pairs)

### 数据结构
```python
trade_pairs: list[dict]  # 字典列表，每个字典代表一个完整的开平仓配对
```

### 字典字段说明

每个 `trade_pairs` 中的字典包含以下字段：

```python
{
    "open_dt": datetime,      # 开仓时间 (datetime对象)
    "open_price": float,      # 开仓价格
    "close_dt": datetime,     # 平仓时间 (datetime对象)
    "close_price": float,     # 平仓价格
    "direction": Direction,   # 持仓方向 (Direction.LONG 或 Direction.SHORT)
    "volume": float          # 交易量（仓位大小）
}
```

### 字段详细说明

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `open_dt` | `datetime` | 开仓时间，来自开仓交易的 `datetime` | `2025-08-07 04:15:00+08:00` |
| `open_price` | `float` | 开仓价格，来自开仓交易的 `price` | `4051.6` |
| `close_dt` | `datetime` | 平仓时间，来自平仓交易的 `datetime` | `2025-08-07 12:30:00+08:00` |
| `close_price` | `float` | 平仓价格，来自平仓交易的 `price` | `4100.0` |
| `direction` | `Direction` | 持仓方向，来自开仓交易的 `direction`<br>注意：使用开仓交易的方向，不是平仓交易的 | `Direction.LONG` 或 `Direction.SHORT` |
| `volume` | `float` | 交易量，取开仓和平仓交易量的最小值 | `0.05593620250122478` |

### 生成逻辑

`trade_pairs` 由 `generate_trade_pairs()` 函数生成，该函数：
1. 将原始交易列表（`TradeData` 对象列表）按开平仓配对
2. 只处理 `Offset.OPEN` 和 `Offset.CLOSE` 的交易
3. 使用 LIFO（后进先出）匹配策略

### 示例数据

```python
[
    {
        "open_dt": datetime(2025, 8, 7, 4, 15, 0),
        "open_price": 4051.6,
        "close_dt": datetime(2025, 8, 7, 12, 30, 0),
        "close_price": 4100.0,
        "direction": Direction.LONG,
        "volume": 0.05593620250122478
    },
    {
        "open_dt": datetime(2025, 8, 7, 13, 20, 0),
        "open_price": 4105.0,
        "close_dt": datetime(2025, 8, 8, 8, 0, 0),
        "close_price": 4080.0,
        "direction": Direction.SHORT,
        "volume": 0.0488
    }
]
```

## 3. 索引映射关系

### 3.1 时间到索引映射 (dt_ix_map)

#### 数据结构
```python
dt_ix_map: dict[datetime, int]  # {datetime: 索引}
```

#### 说明
- **键**: K线的 `datetime` 对象
- **值**: 该K线在 `history` 列表中的索引位置（从0开始）

#### 用途
将交易配对中的 `open_dt` 和 `close_dt` 转换为图表上的X轴坐标（索引）

#### 示例
```python
{
    datetime(2025, 8, 7, 4, 15, 0): 100,  # 第100根K线
    datetime(2025, 8, 7, 12, 30, 0): 150, # 第150根K线
    ...
}
```

### 3.2 索引到K线映射 (ix_bar_map)

#### 数据结构
```python
ix_bar_map: dict[int, BarData]  # {索引: BarData对象}
```

#### 说明
- **键**: K线在 `history` 列表中的索引位置
- **值**: 对应的 `BarData` 对象

#### 用途
根据索引快速查找K线数据，用于：
- 确定箭头位置（开仓箭头在 `low_price` 或 `high_price` 附近）
- 获取K线的价格信息

#### 示例
```python
{
    100: BarData(datetime=..., open_price=4050, high_price=4055, low_price=4048, ...),
    150: BarData(datetime=..., open_price=4100, high_price=4105, low_price=4098, ...),
    ...
}
```

## 4. 绘图元素数据结构

### 4.1 交易线条 (Trade Line)

#### 数据结构
```python
x: list[int] = [open_ix, close_ix]  # X轴坐标（索引列表）
y: list[float] = [open_price, close_price]  # Y轴坐标（价格列表）
color: str = "r" | "g"  # 线条颜色：r=盈利（红色），g=亏损（绿色）
```

#### 颜色判断逻辑
```python
if direction == Direction.LONG and close_price >= open_price:  # 做多盈利
    color = "r"  # 红色
elif direction == Direction.SHORT and close_price <= open_price:  # 做空盈利
    color = "r"  # 红色
else:  # 亏损
    color = "g"  # 绿色
```

### 4.2 箭头标记 (Scatter Points)

#### 数据结构
```python
scatter_data: list[dict]  # 字典列表，每个字典代表一个箭头标记
```

#### 字典字段
```python
{
    "pos": tuple[int, float],      # 位置：(索引, 价格)
    "size": int,                   # 箭头大小，固定为 10
    "pen": QtGui.QPen,             # 画笔（颜色）
    "brush": QtGui.QBrush,         # 画刷（填充颜色）
    "symbol": str                  # 箭头符号："t" 向下，"t1" 向上
}
```

#### 箭头位置和符号规则

**多头交易 (Direction.LONG)**:
- 开仓箭头（向上）：`symbol="t1"`, 位置在 `low_price` 下方
- 平仓箭头（向下）：`symbol="t"`, 位置在 `high_price` 上方
- 颜色：黄色 (`yellow`)

**空头交易 (Direction.SHORT)**:
- 开仓箭头（向下）：`symbol="t"`, 位置在 `high_price` 上方
- 平仓箭头（向上）：`symbol="t1"`, 位置在 `low_price` 下方
- 颜色：紫红色 (`magenta`)

#### 位置计算
```python
y_adjustment = price_range * 0.001  # 价格范围的0.1%，用于调整箭头与K线的距离

# 多头开仓
open_y = open_bar.low_price
open_pos = (open_ix, open_y - 1 * y_adjustment)  # 在K线下方

# 多头平仓
close_y = close_bar.high_price
close_pos = (close_ix, close_y - (-1) * y_adjustment)  # 在K线上方
```

### 4.3 仓位数字文本 (Position Numbers)

#### 数据结构
```python
text_items: list[pg.TextItem]  # TextItem 对象列表
```

#### 文本内容
```python
text = f"[{volume}]"  # 格式：[交易量]
```

#### 位置计算
```python
# 文本位置在箭头位置的基础上，再偏移3倍 y_adjustment
text_y = arrow_y - side * y_adjustment * 3
text_pos = (ix, text_y)
```

#### 颜色
- 多头：黄色（与箭头颜色一致）
- 空头：紫红色（与箭头颜色一致）

## 5. 数据流转过程

### 5.1 数据准备阶段

```python
# 1. 更新K线历史数据
update_history(history: list[BarData])
    ├─ 建立 dt_ix_map: {datetime → index}
    └─ 建立 ix_bar_map: {index → BarData}

# 2. 更新交易数据
update_trades(trades: list[TradeData])
    └─ generate_trade_pairs(trades)
        └─ 返回 trade_pairs: list[dict]
```

### 5.2 绘图阶段

```python
for d in trade_pairs:
    # 1. 时间转索引
    open_ix = dt_ix_map[d["open_dt"]]
    close_ix = dt_ix_map[d["close_dt"]]
    
    # 2. 绘制交易线条
    draw_line([open_ix, close_ix], [open_price, close_price])
    
    # 3. 获取K线数据
    open_bar = ix_bar_map[open_ix]
    close_bar = ix_bar_map[close_ix]
    
    # 4. 绘制箭头
    draw_arrow(open_ix, open_bar.low_price/high_price, direction)
    draw_arrow(close_ix, close_bar.high_price/low_price, direction)
    
    # 5. 绘制仓位数字（可选）
    draw_text(open_ix, open_y, volume)
    draw_text(close_ix, close_y, volume)
```

## 6. 关键数据依赖关系

```
TradeData (原始交易数据)
    ↓
generate_trade_pairs()
    ↓
trade_pairs (交易配对数据)
    ↓
update_trades()
    ├─ dt_ix_map (时间 → 索引) ← update_history() 建立
    ├─ ix_bar_map (索引 → K线) ← update_history() 建立
    └─ 绘制图表元素
```

**重要**: `update_history()` 必须在 `update_trades()` 之前调用，因为绘图需要 `dt_ix_map` 和 `ix_bar_map` 的映射关系。

---

## 7. 数据验证要点

1. **时间匹配**: `trade_pairs` 中的 `open_dt` 和 `close_dt` 必须能在 `dt_ix_map` 中找到对应的索引
2. **方向正确**: `direction` 字段应使用开仓交易的方向，不是平仓交易的方向
3. **价格合理**: `open_price` 和 `close_price` 应在K线的价格范围内
4. **成交量一致**: 配对的开仓和平仓交易量应该匹配（或接近）

---

## 总结

绘图元数据的核心是：
1. **K线数据** → 提供价格和时间轴
2. **交易配对** → 提供开平仓关系
3. **索引映射** → 将时间坐标转换为图表坐标

这三部分数据配合，可以完整绘制出带交易标记的K线图表。
