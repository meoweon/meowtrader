# 交易所对接列表

## 一、Gateway 与 Datafeed 的区别

### Gateway（交易接口）

**定义**：Gateway 是连接交易系统的接口，用于**实时交易**和**实时行情**。

**特点**：
- 继承 `BaseGateway` 基类
- 必须实现：`connect()`, `subscribe()`, `send_order()`, `cancel_order()` 等方法
- 可以**下单交易**、**查询持仓**、**查询账户**
- 提供**实时行情**（Tick 数据）
- 配置在 `config/edition.*.json` 的 `gateways` 数组中

**示例**：
- `vnpy_ctp` - CTP 期货接口（可交易）
- `vnpy_okx` - OKX 交易所接口（可交易）
- `vnpy_xt` - 迅投研数据服务（可作为 Gateway 使用，提供行情）

### Datafeed（数据服务）

**定义**：Datafeed 是历史数据查询服务，用于**回测**和**数据分析**，**不能交易**。

**特点**：
- 继承 `BaseDatafeed` 基类
- 主要方法：`query_bar_history()`, `query_tick_history()`
- **只能查询历史数据**，不能下单交易
- 用于策略回测、数据分析
- 配置在全局设置的 `datafeed.name` 中

**示例**：
- `vnpy_tqsdk` - 天勤数据（Datafeed，不是 Gateway）
- `vnpy_rqdata` - 米筐数据
- `vnpy_tushare` - Tushare 数据

### 天勤（tqsdk）说明

**重要**：`vnpy_tqsdk` 是 **Datafeed**，不是 Gateway！

**使用方式**：
1. **安装**：`uv sync --extra tqsdk` 或 `uv pip install vnpy-tqsdk`
2. **配置**：在全局配置中设置 `datafeed.name = "tqsdk"`
3. **用途**：用于查询历史 K 线、Tick 数据，用于策略回测
4. **不能**：不能作为 Gateway 使用，不能实时交易

**配置示例**：
```json
{
  "datafeed": {
    "name": "tqsdk"
  }
}
```

**注意**：
- `vnpy_tqsdk` 导出的是 `Datafeed` 类，不是 `TqsdkGateway`
- 不要将 `tqsdk` 添加到 `gateways` 配置中
- 天勤数据需要注册账号并配置用户名密码

## 三、如何对接新接口

### 对接 Gateway（交易接口）

#### 步骤1：安装Gateway模块

```bash
# 方式1：使用uv安装（推荐）
uv sync --extra <gateway_name>

# 方式2：使用pip安装
uv pip install vnpy-<gateway_name>
```

#### 步骤2：添加到GATEWAY_MAP

编辑 `core/engine/product_engine.py`，在 `GATEWAY_MAP` 中添加：

```python
GATEWAY_MAP = {
    # ... 现有映射
    "ctp": ("vnpy_ctp", "CtpGateway", "CTP", "cn_futures", "上期技术 CTP 期货接口"),
    "xtp": ("vnpy_xtp", "XtpGateway", "中泰XTP", "cn_stock", "中泰证券 XTP 接口"),
    # ... 其他Gateway
}
```

#### 步骤3：在配置文件中启用

编辑 `config/edition.*.json`，在 `gateways` 数组中添加：

```json
{
  "gateways": [
    {"name": "ctp", "category": "cn_futures"},
    {"name": "xtp", "category": "cn_stock"}
  ]
}
```

#### 步骤4：配置连接参数

在UI界面中：
1. 打开"设置" → "交易接口连接"
2. 选择对应的Gateway
3. 点击"连接"按钮
4. 填写连接参数（API Key、Secret等）
5. 确认连接

### 对接 Datafeed（数据服务）

#### 步骤1：安装Datafeed模块

```bash
# 方式1：使用uv安装（推荐）
uv sync --extra <datafeed_name>

# 方式2：使用pip安装
uv pip install vnpy-<datafeed_name>
```

#### 步骤2：配置Datafeed

在全局配置中设置（通过UI的"全局配置"或直接编辑配置文件）：

```json
{
  "datafeed": {
    "name": "tqsdk"
  }
}
```

**注意**：
- Datafeed **不需要**添加到 `GATEWAY_MAP`
- Datafeed **不需要**添加到 `gateways` 配置
- 只需要在全局配置中设置 `datafeed.name`

#### 步骤3：使用Datafeed

Datafeed 会在以下场景自动使用：
- 策略回测时查询历史数据
- 数据管理模块下载历史数据
- 图表模块加载历史K线

**天勤（tqsdk）特殊说明**：
- 安装：`uv sync --extra tqsdk`
- 配置：`datafeed.name = "tqsdk"`
- 需要：注册天勤账号并配置用户名密码
- 用途：查询国内期货、股票的历史数据

## 五、注意事项

### Gateway 相关

1. **账户要求**：大部分Gateway需要对应的交易账户和接口授权
2. **测试环境**：建议先用测试接口（如CTP测试、TTS）熟悉流程
3. **配置位置**：
   - Gateway 定义在 `core/engine/product_engine.py` 的 `GATEWAY_MAP`
   - Gateway 启用配置在 `config/edition.*.json` 的 `gateways` 数组
4. **依赖管理**：使用 `uv sync --extra <name>` 或 `uv pip install vnpy-<name>` 安装

### Datafeed 相关

1. **Datafeed vs Gateway**：
   - **Gateway**：可以交易 + 实时行情
   - **Datafeed**：只能查询历史数据，不能交易
2. **天勤（tqsdk）**：
   - ⚠️ **是 Datafeed，不是 Gateway**
   - 不要添加到 `gateways` 配置
   - 需要在全局配置中设置 `datafeed.name = "tqsdk"`
   - 需要注册天勤账号
3. **配置位置**：Datafeed 配置在全局设置的 `datafeed.name` 中
4. **使用场景**：主要用于策略回测、历史数据分析

### 常见问题

1. **Q: 为什么天勤加载失败？**  
   A: 天勤是 Datafeed，不是 Gateway。不要将它添加到 `gateways` 配置，而是在全局配置中设置 `datafeed.name = "tqsdk"`

2. **Q: 如何区分 Gateway 和 Datafeed？**  
   A: Gateway 继承 `BaseGateway`，可以交易；Datafeed 继承 `BaseDatafeed`，只能查询历史数据

3. **Q: 迅投XT 是 Gateway 还是 Datafeed？**  
   A: 迅投XT 是 Gateway（`vnpy_xt.XtGateway`），可以作为 Gateway 使用，提供实时行情

### talib.stream

- **作用**：提供流式技术指标计算功能，适合实时数据流处理场景

### vnpy_mini

- **作用**：对接上海期货信息技术有限公司（上期技术）的 CTP Mini 期货接口
- **支持的交易所**：CFFEX, SHFE, CZCE, DCE, INE, GFEX
- **产品类型**：期货、期权
- **安装问题**：包含需要编译的 `.pyd` 文件（Python 扩展模块），无法通过 `pip` 直接安装
- **解决方案**：从 `veighna_studio` 手动复制已编译的包到 `.venv/Lib/site-packages/`
- **状态**：✅ 已从 veighna_studio 复制，可以正常使用

### vnpy_ksgold

**`vnpy_ksgold`** 是金仕达黄金交易接口。

- **作用**：对接金仕达软件技术有限公司的黄金 TD 交易接口
- **支持的交易所**：SGE（上海黄金交易所）
- **产品类型**：黄金TD（延期交收合约）
- **安装问题**：包含需要编译的 `.pyd` 文件（`vnksgoldmd.pyd`, `vnksgoldtd.pyd`），这些文件需要从源码编译
- **编译要求**：需要 Visual C++ 编译器和相关依赖
- **解决方案**：
